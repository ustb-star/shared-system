此 skill 用于指导创建有辨识度、生产级的前端界面，避免普通、模板化、AI 味过重的视觉风格。实现真实可运行的代码，并特别关注审美细节和创意选择。

用户会提供前端需求：要构建的组件、页面、应用或界面。他们可能同时提供用途、受众、技术约束等背景信息。

## 设计思考

编码前，先理解上下文，并明确采用一个鲜明的审美方向：
- **用途**：这个界面解决什么问题？谁会使用它？
- **气质**：选择一个明确的方向，例如极简克制、极繁混沌、复古未来、自然有机、奢华精致、玩具般有趣、编辑部杂志感、粗粝野兽派、装饰艺术几何、柔和粉彩、工业工具感等。可从这些方向获得灵感，但最终设计必须服务于当前场景。
- **约束**：技术要求，例如框架、性能、可访问性。
- **差异化**：它最让人记住的一点是什么？用户看完后会记住什么？

**关键要求**：选择清晰的概念方向，并精准执行。大胆的极繁主义和克制的精致极简都可以成立，重点是设计意图清楚，而不是单纯追求强烈。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），并确保它：
- 达到生产级质量且功能完整
- 视觉上有冲击力并容易被记住
- 具备统一且清晰的审美观点
- 在每个细节上都有打磨

## 前端审美准则

重点关注：
- **字体**：选择美观、独特、有性格的字体。避免 Arial、Inter 等过于常见的默认选择；改用能提升界面质感的字体组合。可以用一个有辨识度的展示字体搭配一个精致的正文字体。
- **颜色与主题**：坚持统一的审美体系。使用 CSS 变量保持一致性。明确的主色加锐利强调色，通常比平均分配、缺乏态度的配色更有效。
- **动效**：使用动画表达效果和微交互。HTML 场景优先考虑纯 CSS 方案；React 场景可在已有条件允许时使用 Motion 类库。优先打造高影响力时刻：一次编排良好的页面加载、带延迟的分层出现，往往比零散的微交互更有记忆点。使用滚动触发和有惊喜感的 hover 状态。
- **空间构成**：尝试非预期布局、不对称、重叠、斜向动线、突破网格的元素、大量留白或受控密度。
- **背景与视觉细节**：不要默认使用纯色背景；要营造氛围和层次。加入与整体审美一致的上下文效果和纹理，例如渐变网格、噪声纹理、几何图案、层叠透明、戏剧化阴影、装饰性边框、自定义光标、颗粒覆盖层等。

不要使用常见的 AI 生成式审美套路，例如过度使用 Inter、Roboto、Arial、系统字体，套用陈词滥调的配色（尤其是白底紫色渐变），采用可预测的布局和组件模式，或做出缺少场景个性的模板化设计。

要创造性地解读需求，并做出真正适合当前场景的非预期选择。不要让每次设计都长得一样。可以在亮色与暗色主题、不同字体、不同审美方向之间切换。不要在多次生成中总是收敛到同一批常见选择，例如反复使用 Space Grotesk。

**重要**：实现复杂度要匹配审美目标。极繁设计需要更丰富的代码、动画和视觉效果；极简或精致设计需要克制、精准，并仔细处理间距、字体和微妙细节。真正的优雅来自对设计意图的准确执行。

记住：Codex 可以完成高质量的创意前端工作。不要保守，要跳出模板化思路，并完整投入到一个有辨识度的设计方向中。
