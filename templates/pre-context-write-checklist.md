# Context 写入前检查清单

本清单用于处理大资料包、历史 PRD 包、带截图和外部工作项的资料包时，在正式写入 `context/` 前完成门禁检查。它也可用于写入后的质量复盘。

## 1. 来源覆盖

| 来源类型 | 是否存在 | 是否已读/归档 | 缺口 |
|---|---|---|---|
| intake.md / 批次说明 |  |  |  |
| source prd / 历史 PRD |  |  |  |
| release note |  |  |  |
| screenshots / 当前截图 |  |  |  |
| standard docs / 操作或培训文档 |  |  |  |
| dev docs / 技术方案 |  |  |  |
| Excel/WPS/CSV 表格 |  |  |  |
| 外部工作项归档 |  |  |  |
| project / 项目材料 |  |  |  |

## 2. 外部工作项完整性

文件名或目录名包含“云效”关键词，或表格/正文存在云效 URL 时，必须完成本节。

| 校验项 | 数量/结果 | 缺口 |
|---|---|---|
| 解析出的云效链接数 |  |  |
| 工作项主体抓取数 |  |  |
| 评论检查数 |  |  |
| 动态/变更历史检查数 |  |  |
| 附件元数据检查数 |  |  |
| 附件下载归档数 |  |  |
| 抓取失败记录 |  |  |

未完成评论、动态或附件检查时，不要把对应工作项提炼为稳定 `context/`。

## 4. 当前状态归并

| 检查项 | 结论 |
|---|---|
| 当前最新版本或当前截图口径 |  |

功能正文只写当前有效状态。版本演进、历史命名、已废弃能力和过程性讨论进入版本记录、废弃说明或 drafts。

## 5. 写入颗粒度

| 模块类型 | 必须覆盖 | 是否满足 |
|---|---|---|
| 产品架构 | 定位、边界、核心实体、上下游、产品自有能力与外部依赖 |  |
| 列表 | 筛选项、列表字段、字段来源、操作、权限、异常入口 |  |
| 表单 | 分组、字段来源、校验、默认值、引用、保存和提交交互 |  |
| 状态机 | 当前状态枚举、模式差异、角色差异、列表/详情操作、批量操作范围 |  |
| 配置模块 | 配置入口、配置项、枚举、校验、保存方式、生效范围、上下游影响 |  |
| BI / 报表 | 指标口径、筛选项、图表/表格、数据来源、统计周期、权限 |  |
| 版本记录 | 上线时间、版本核心内容、影响模块、云效零散需求合并摘要、来源 |  |

## 6. 写法检查

| 检查项 | 是否存在 | 处理方式 |
|---|---|---|
| 补丁式追加说明 |  | 优先回并原章节或原表格 |
| 新旧口径并存 |  | 删除旧口径或迁移到版本记录 |
| 历史过程写入功能正文 |  | 移到版本记录 |
| 重复专题文档 |  | 合并或更新 AGENTS 指向主文档 |
| 来源只挂在概览，专题缺来源 |  | 补到对应专题文档 |
| 颗粒度只有摘要级 |  | 补到字段、列表、表单、状态或指标级 |

## 7. 输出计划

| 目标文件 | 写入方式 | 原因 |
|---|---|---|
|  | 新建 / 改写 / 合并 / 删除旧口径 |  |

写入时优先改写和整合现有文档。只有主题独立、长期复用且会让原文档过长时才新建专题文档。
