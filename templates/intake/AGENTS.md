# Intake Template

## Purpose

这个目录提供“发起一次知识库更新”所需的标准模板。

它面向的场景是：用户把一批待处理文件放入某个目录，然后用统一的说明文件和统一的指令格式，交给 Codex 判断路由、归档和提炼 context。

## What To Read First

- [README.md](README.md) - 使用说明
- [intake.md](intake.md) - 说明文件模板
- [intake-sample.md](intake-sample.md) - 已填写示例
- [request-template.md](request-template.md) - 发起指令模板

## Files

- `README.md` - 如何组装一个待处理目录
- `intake.md` - 批次说明文件模板，包含当前口径、产品边界、外部工作项提示和重点输出模块
- `intake-sample.md` - 示例化填写方式，用于说明口径、边界、文件说明和粒度要求
- `request-template.md` - 给 Codex 的标准请求模板，包含来源完整性和当前状态归并要求

## Routing Rules

- 这里放模板，不放真实待处理材料
- 真实材料应放到单独的 incoming 目录，再配套使用这里的模板

## Maintenance Notes

- 如果 intake 字段调整，`README.md`、`intake-sample.md` 和 `request-template.md` 要一起更新
