# 材料导入说明（示例）

> 这是一个填写示例，用来说明 `intake.md` 应该给到什么粒度的信息。真实资料包请复制 `intake.md` 模板后按实际产品线填写，不要直接复用示例中的产品名、版本号或判断结论。

## 基本信息

| 字段 | 内容 |
|---|---|
| 批次名称 | 2026-05 某产品线现状资料整理 |
| 产品线 / 仓库 | `context-example-product` |
| 材料目录 | `D:\1data\incoming\2026-05-example-current-state` |
| 目标 | 归档来源材料，并把已上线、可复用的产品现状写入 context |
| 敏感级别 | 内部资料；客户名、合同价、账号、token 不写入 context 正文 |
| 不做事项 | 本轮不写 kb，不生成对外材料 |

## 当前口径

| 项目 | 当前口径 |
|---|---|
| 当前最新版本 | 以 `release notes`、当前截图和最新开发文档共同确认的状态为准 |
| 主要模块命名 | 全部邮件、委托接单、文件建单、接单配置、运营平台、BI 看板 |
| 已废弃 / 已改名概念 | “异常委托列表”已调整为“全部邮件”；如果来源中仍出现旧名，只作为历史来源追溯 |
| 写入方式 | context 只沉淀当前结果，不写版本演进过程；版本演进只进入 `05_版本记录` |

## 产品边界提示

| 类型 | 口径 |
|---|---|
| 产品自有能力 | 状态流转、字段校验、业务规则配置、列表与详情交互、分配规则 |
| 外部依赖 | AI 内容识别、外部数据通道、第三方系统同步 |
| 易混淆边界 | SaaS 用户侧配置和内部运营平台是两个独立模块，需要分开写 |
| 未来方向 | 未来规划只能写在“规划/待确认”段落，不能覆盖当前已上线口径 |

## 文件说明

| 路径 / 文件 | 类型 | 处理要求 |
|---|---|---|
| `source\source prd\` | PRD / 历史需求 | 读取全部版本，按当前现状归并，不按版本逐段堆叠 |
| `source\dev docs\` | 技术方案 / 开发文档 | 用于确认状态机、数据模型、字段、接口和系统边界 |
| `source\screenshots\` | 产品截图 | 用于校对当前列表、表单、按钮、筛选、字段展示 |
| `source\standard docs\` | 操作手册 / 培训文档 | 用于补足使用视角、操作步骤和业务规则解释 |
| `source\*云效*.xlsx` | 外部工作项索引 | 必须用云效 skill 获取 URL 对应工作项详情、评论、动态、附件和内联图片 |

## 外部工作项提示

- 文件名或目录名只要包含“云效”，就需要触发云效工作项读取。
- 表格中的 URL 列不是普通来源链接，需要进一步获取工作项正文、评论、动态和附件。
- 云效信息进入 context 时，需要与 PRD、截图、开发文档合并成当前事实，不单独追加一个“云效补充”章节。

## 重点输出模块

| 模块 | 需要达到的粒度 |
|---|---|
| 列表 | 每个 Tab 的数据范围、筛选、字段、状态、批量操作和跳转 |
| 详情表单 | 字段分组、只读 / 可编辑逻辑、按钮、异常提示、保存 / 提交流程 |
| 状态机 | 按模式拆分状态、可操作项、操作者、前置条件和结果 |
| 配置模块 | 每一步配置项、字段枚举、条件、默认值、优先级和生效范围 |
| BI 看板 | 页面结构、筛选、指标口径、图表、明细表和数据来源 |

## 写入偏好

- 优先改写和归并已有文档，不用追加式补丁章节承接遗漏信息。
- 功能模块文档写当前最新结果；版本号、需求号和变更过程放到来源或版本记录。
- 对有冲突的来源，按“当前截图 / 最新开发文档 > 最新 PRD > 历史 PRD > 口头补充”的顺序判断，并在文档中保留必要的不确定性说明。
